# Privacy Policy

**Last updated:** July 2026

## Introduction

Student OS ("we," "our," or "the app") is an offline-first student productivity workspace. This Privacy Policy explains what information is collected, how it is used, and your rights regarding your data.

Student OS is designed with privacy as a core principle. **No account is required. No data is sent to any server. All data stays on your device.**

## What We Collect

### Information You Provide

- **User name:** A name you choose to personalize the app. Stored locally on your device.
- **Avatar selection:** Your chosen avatar. Stored locally.
- **Academic goal:** An optional goal you set (e.g., "IIT Bombay"). Stored locally.
- **Study style preferences:** Your selected study style. Stored locally.

### Information Generated by Your Usage

- **Tasks:** Task titles, descriptions, subjects, due dates, completion status. Stored locally.
- **Habits:** Habit names, completion history. Stored locally.
- **Focus sessions:** Duration, start/end times, subject tags, focus scores. Stored locally.
- **Study events:** Calendar events, planner entries. Stored locally.
- **Focus Shield (Deep Lock) data:** Blocked app names, distraction timestamps, interruption counts. Stored locally.
- **Preferences:** Theme selection, timer settings, daily goals, display preferences. Stored locally.

## What We Do NOT Collect

Student OS **does not collect, transmit, or share** any of the following:

- Personal identifiers (email, phone number, address)
- Login credentials or passwords
- Financial information
- Location data
- Contact lists
- Photos, media, or files
- Browsing history
- Biometric data
- Health information
- Device identifiers (IMEI, serial number)
- Usage analytics or telemetry (unless explicitly enabled by the user)

## Accessibility Service Usage

<!-- Sync source: components/compliance/accessibility-claims.ts (keep these paragraphs verbatim) -->

Student OS uses the Android Accessibility Service **exclusively** for the Deep Lock feature during Focus Sessions.

**Purpose:** Student OS uses the Android Accessibility Service to detect the foreground app during user-initiated focus sessions, in order to block distracting apps as part of the Deep Lock feature.

### Data Types Collected

#### Other personal info

The package name and display name of the app in the foreground (e.g., "Instagram"). This identifies which app the user is using, not any content within it.

#### Other user-generated content

A local log of blocked-app attempts during focus sessions, containing the app name, timestamp, and session reference. This is user-facing history shown in the app's distraction log.

### What the Accessibility Service Does

- Detects which app is in the foreground when a Focus Session is active.
- Identifies blocked apps so the warning screen can be shown.
- Logs distraction attempts for analytics.

### What the Accessibility Service Does NOT Do

- **Does not** read screen content, passwords, messages, or text input.
- **Does not** capture keystrokes or touch input.
- **Does not** access personal communications (email, chat, social media content).
- **Does not** modify system settings outside of Focus Sessions.
- **Does not** transmit any data off your device.
- **Does not** read content from banking apps, password managers, or encrypted apps.

The Accessibility Service does NOT read screen content, keystrokes, passwords, messages, or any data from apps not in the foreground. It is never active outside a user-started focus session and can be revoked at any time via Android Settings.

All data stays on-device. Nothing is transmitted to our servers or third parties.

The Accessibility Service is **only active** when a Focus Session is running and Deep Lock is enabled. It is disabled at all other times.

Users are shown a full-screen prominent disclosure explicitly naming these data types before the permission is requested, and must explicitly acknowledge it before the permission dialog opens.

## Foreground Service Usage

Student OS runs a Foreground Service during Focus Sessions to:

- Maintain the timer accuracy when the app is in the background.
- Enable Deep Lock to continue monitoring blocked apps.
- Show a persistent notification indicating an active Focus Session.

The Foreground Service is started when a Focus Session begins and is stopped when the session ends.

## Data Storage

All data is stored **locally on your device** using:

- **localStorage:** Application state, preferences, tasks, habits, sessions, events.
- **SharedPreferences (Android):** Focus Shield statistics and distraction records.
- **IndexedDB (optional):** Used for data export/import functionality.

**No data is stored on remote servers, cloud services, or third-party infrastructure.**

## Data Export and Deletion

### Export

You can export all your data as a JSON file at any time from Settings → Data → Export. The exported file is a complete snapshot of all information stored by the app.

### Deletion

You can delete all app data from Settings → Data → Clear All Data. This permanently removes all local data. Alternatively, uninstalling the app removes all locally stored data.

## Analytics

Student OS does **not** include any analytics SDK, telemetry library, or tracking framework. No usage data is sent to us or any third party.

If we add optional analytics in the future, it will be opt-in only and clearly disclosed.

## Notifications

Student OS may request notification permissions to:

- Alert you when a Focus Session completes.
- Inform you when a blocked app was detected during a session.

Notifications are processed locally. No notification data is transmitted off your device.

## Deep Lock

Deep Lock is an optional feature that uses the Accessibility Service and Foreground Service to help you stay focused during study sessions. It is **off by default** and must be explicitly enabled by you.

### How Deep Lock Works

1. You start a Focus Session with Deep Lock enabled.
2. The Accessibility Service monitors foreground app changes.
3. If a blocked app is detected, a full-screen warning is shown.
4. You can choose to return to focus or dismiss the warning.
5. Distraction attempts are recorded for your personal analytics.

### Data Collected by Deep Lock

- **Blocked app package name** (e.g., "com.instagram.android")
- **Blocked app display name** (e.g., "Instagram")
- **Timestamp of each distraction attempt**
- **Session ID for correlation**

This data is stored locally and used only to display distraction analytics within the app.

## Children's Privacy

Student OS is designed for students of all ages, including those under 13. Since no personal information is collected, transmitted, or shared, the app complies with children's privacy regulations including COPPA (Children's Online Privacy Protection Act).

## Your Rights

Since all data is stored locally on your device, you have full control:

- **Right to access:** All your data is visible within the app. You can also export it as JSON.
- **Right to deletion:** Clear all data from Settings or uninstall the app.
- **Right to portability:** Export your data as a downloadable JSON file.
- **Right to restrict processing:** Disable any feature (Deep Lock, notifications, etc.) at any time.
